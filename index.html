Package Maintainer Finder NEW
Real npm package authors & maintainers — Live API, real emails
Calls npm's public registry search API live (no X-Ray needed). For each matched package, extracts the author/maintainer name, email (when publicly listed), repository link, and a popularity score from download stats. The only platform that can return a real, working email address directly.
Live API — registry.npmjs.org Real emails (when public) Best for: Backend / Python / JS
